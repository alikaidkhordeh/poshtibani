# چت پشتیبانی کلینیک (ننه پت)

چت‌بات پشتیبانی آنلاین کلینیک دکتر زاهدی: مراجعه‌کننده‌ها در `https://chat.enetvip.com` گفتگو می‌کنند و
کلینیک همه‌چیز را در `https://chat.enetvip.com/admin` مدیریت می‌کند. ربات فقط از دیتابیس خود کلینیک جواب می‌دهد.

راهنمای نصب روی سرور: [deploy/README.md](deploy/README.md)
